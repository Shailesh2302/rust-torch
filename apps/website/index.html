01 — Install

One line, one dependency.

cargo add rust-torch

Requires Rust 1.70+. No system libraries, no Python bridge.

Cargo.toml

[dependencies]
rust-torch = "0.1.0"

Import

use rust_torch::{Tensor, nn::{GPT, GPTConfig, Module}};

02 — Guide

From tensor to trained model.

1 Differentiate anything

let w = Tensor::randn(&[8, 4]);
w.set_requires_grad(true);
let y = x.matmul(&w).relu().mean();
y.backward();

Broadcasting, batched matmul, softmax, embedding, and fused cross-entropy all record onto the tape.

2 Stack a transformer

let cfg = GPTConfig {
    vocab_size: 65, block_size: 16,
    n_layer: 2, n_head: 2,
    n_embd: 32, dropout: 0.0, bias: true,
};
let model = GPT::new(cfg);
let logits = model.forward(&ids, 2, 16);

Pre-norm blocks, causal attention, GELU MLPs — plus a LLaMA variant with RMSNorm, RoPE, and SwiGLU.

3 Train and sample

let mut opt = AdamW::new(model.parameters(), 3e-3);
opt.zero_grad();
let loss = model.loss(&logits, &targets);
loss.backward();
opt.step();

let out = model.generate(prompt, 40, 0.8, Some(20));

Temperature, top-k, and top-p decoding included.

03 — Examples

Copy, run, adapt.

cargo run --example sample
cargo run --release --example train_gpt

Char-level training

let tok = CharTokenizer::build(&corpus);
let ids = tok.encode(&corpus);
let (train, _) = TextDataset::split_train_val(ids, 16, 0.1);
let (xs, ys, b, t) = train.random_batch(4);
let loss = model.loss(&model.forward(&xs, b, t), &ys);

Checkpoints

rust_torch::utils::save_checkpoint("gpt.bin", &model.parameters())?;
rust_torch::utils::load_checkpoint("gpt.bin", &model.parameters())?;

04 — Reference

Eight modules, nothing hidden.

tensor

Row-major Tensor, dynamic autograd, no_grad inference.

nn

Linear, Embedding, norms, attention, GPT / LLaMA.

optim

SGD, Adam, AdamW, cosine schedule.

loss

MSE, cross-entropy, LM loss, BCE with logits.

data

Next-token batches from a flat token stream.

tokenizer

Char- and word-level tokenizers.

sampling

Temperature, top-k, nucleus sampling.

utils

Seeding, param counts, binary checkpoints.
